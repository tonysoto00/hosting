Solved-Promoter

Android Laravel API GPS Tracking Vue.js

Solución de software integral para la administración y control de la fuerza de ventas. Permite coordinar centralizadamente a promotores de ventas y mensajeros en campo, registrando cada transacción por medio de tickets de venta en tiempo real. Cuenta con un completo sistema para el control de productos en almacén (inventario físico de entrada y merma) y a la venta (stock disponible en catálogo), facilitando la supervisión operativa y la liquidación de pagos.

  • Gestión y control de vendedores por tickets de venta
  • Administración de productos en almacén e inventario a la venta
  • Control operativo y de rutas para mensajeros y promotores
  • Módulo de liquidaciones, pagos y ranking de ventas

Mi Pokemon

CakePHP MySQL Vue.js APIs Integration

Plataforma web especializada en la comunidad de cartas coleccionables Pokémon (TCG). Permite a los coleccionistas consultar precios actualizados del mercado, gestionar inventarios de cartas, realizar ofertas de intercambio seguras y comprar o vender cartas directamente entre usuarios con total transparencia.

  • Consulta y cotización de precios de cartas en tiempo real
  • Marketplace para compra y venta directa entre usuarios
  • Módulo de intercambio seguro y control de ofertas
  • Panel de control interactivo desarrollado en Vue.js

Colección Deportiva

Python PostgreSQL HTML /CSS APIs Integration Django VUE JS

Plataforma web diseñada para coleccionistas de cromos deportivos (fútbol, baloncesto, béisbol y más). Permite registrar álbumes virtuales completo, llevar el control de cromos repetidos y faltantes, cotizar el valor de mercado en tiempo real, y gestionar ofertas de intercambio inteligentes y seguras directamente con otros coleccionistas.

  • Gestión de álbumes virtuales y control de cromos repetidos/faltantes
  • Valuación y cotización histórica de cromos coleccionables
  • Ofertas automáticas de intercambio directo entre usuarios
  • Panel de control responsivo desarrollado en Vue.js
